# Route art

Decorative silkscreen idea from the v1 spec (§6.4): lines from the chip, through each ring LED, out to its EdgeLock contact, routed on one layer so nothing crosses. Decorative only; it does not follow the real copper.

- `picomondo_art.kicad_pro` / `picomondo_art.kicad_pcb`: art-only board (outline, LED ring and connector positions as graphics; no footprints).
- `picomondo_art_routed.kicad_pcb`: the same board after single-layer autorouting.
- `picomondo_art_routed_FCu.svg`: F.Cu exported from the routed board, ready to finish in a vector editor.
- `PicoMondo_v1_route_art.svg`, `PicoMondo_v1_board_art.vectorcraft`: the finished artwork (VectorCraft source and SVG export).

Not yet applied to the real board.
