# PicoMondo v1 (reduced scope): first build

Generated by Claude, 2026-10-26. Built from `rp2350b_minimal` (the Pi reference design, used for the MCU core and its layout) and `picomondo_creep` (the old sheets that are still useful).

## Check in KiCad, in this order

1. Delete the empty typo files `picomodo_reduced.*` from this folder, then open `picomondo_reduced.kicad_pro`.
2. Open the schematic and run ERC. The five placeholder sheets (Barrel input, 5V and power priority, USB-C, EdgeLock connectors, NeoPixel and Qwiic) contain notes only, so ERC will flag the global labels that nothing drives yet.
3. Open the PCB and run Update PCB from Schematic (F8). This adds the 20 new indicator footprints (D45–D54, R113–R122) and picks up the net changes listed below.
4. Run DRC. The Pi core block (U1 and its passives, rotated 45°) is one group with its original routing; everything else is parked to the right of the board, grouped by sheet.

## Things to know

- CN1 (Qwiic) uses your JLCImport library, which must be in the global library tables.
- 3D models were not copied. Copy `lib/3dmodels` and `lib/lcsc/lcsc.3dshapes` over from picomondo_creep if you want them.
- The flash and its resistors sit about 70° up and to the right of the chip, out to r ≈ 23 mm. Centre the LED-ring gap there, not at 45°.
- The INA226 is strapped to 0x41; the spec says 0x40. Pick one.
- J8 is still the KF301 screw terminal. It needs to become the 4-circuit EdgeLock with 2+2 paralleled pins.
- J10 (SWD) is a 2.54 mm horizontal header marked DNP. Check that it's what you want on the left edge.
- C16, R9, SW1, SW2 and J10 are MCU-core parts outside the Pi block. Place them by hand.
- There are no copper pours yet. Add GND on In1.
- L1 polarity: pad 1 (the dot) goes on +1V1, as on the Pi board. The old schematic and the February spec had it reversed.

## Schematic changes

- **MCU core:** removed C20, R6, R7, U3 (+5 power symbols, 11 wires, 9 labels, 0 other)
- **MCU core:** spare second-memory footprint (U3) and its select/pull-up/decoupling parts removed (cut from v1)
- **MCU core:** L1 rotated 180 deg: pin 1 (polarity dot) now on +1V1, pin 2 on VREG_LX, matching the Raspberry Pi reference layout
- **3V3 regulator:** removed C40, C41, U5 (+5 power symbols, 4 wires, 3 labels, 0 other)
- **3V3 regulator:** +3V3_AUX regulator removed (it only powered the USB-PD controller, which is cut)
- **Switched output:** removed C44, D5, F2, F4, J7, Q3, Q4, Q7, Q8, R21, R22, R23, R24, R25, R26, R33, R34, R35, R36, U7 (+13 power symbols, 45 wires, 38 labels, 1 other)
- **Switched output:** J7 (5 V) and +5V_SW channels removed; J8 channel (V_INPUT, DMP4015 + INA226 at 0x41) kept
- **Switched output:** enable moved from GPIO9 to GPIO24 (v1 spec GPIO table)
- **Switched output:** removed the +5V_SW PWR_FLAG pair (3 elements)
- **Switched output:** indicator LED D8/R37 now on J8_OUT (was +5V_SW) so it shows voltage actually present on the output
- **Switched output:** R37 470 -> 10k: about 1 mA at 12 V, 2 mA at 24 V (was sized for 5 V); check LCSC part number
- **Board support:** removed TP14, TP15, TP16, TP17, TP7, TP8 (+2 power symbols, 6 wires, 4 labels, 0 other)
- **Board support:** test points for +3V3_AUX, +5V_SW and spare GPIO36-39 removed (rails cut; GPIO36-39 now go to EdgeLocks)
- **Board support:** BUG FIX: GPIO23 label moved from between WS2812 DIN and R108 to R108's far end, so the 100 ohm series resistor is actually in the data path
- **GPIO indicators:** added 10 indicator cells for GPIO8, 9, 20, 21, 34-39 (D45, R113, D46, R114, D47, R115, D48, R116, D49, R117, D50, R118, D51, R119, D52, R120, D53, R121, D54, R122). GPIO20/21 are I2C: their LEDs are DNP by default because a 1 mA LED load fights the 4.7k pull-ups
- **Barrel input:** new placeholder sheet with design notes
- **5V and power priority:** new placeholder sheet with design notes
- **USB-C:** new placeholder sheet with design notes
- **EdgeLock connectors:** new placeholder sheet with design notes
- **NeoPixel and Qwiic:** new placeholder sheet with design notes
